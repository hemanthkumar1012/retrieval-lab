Connecting Source

Ask a question and see how each retriever answers it.

This searches 5,183 scientific abstracts (BEIR SciFact) stored in Postgres. Vector search finds passages with similar meaning, full-text search finds the exact words, rank fusion merges both lists, and a cross-encoder reorders the best twenty. Every stage is timed.

Retrieval mode
  1. Vector searchpgvector HNSW index, cosine similarity on 384-dimension embeddings
  2. Full-text searchPostgres tsvector with OR-ed terms, ranked by ts_rank_cd
  3. Rank fusionReciprocal rank fusion merges the two lists by position, not score
  4. RerankA cross-encoder rereads the top twenty against the question
